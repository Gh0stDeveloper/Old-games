# Old Games

### Preserving classic mobile gaming experiences

Old Games is a repository dedicated to documenting and adapting classic Java ME, Symbian, BlackBerry and early Android mobile games for study and compatibility work on modern devices.

## Game catalog

| Game | Original platform | Project |
| --- | --- | --- |
| [Diamond Rush](games/Diamond-Rush/) | Java ME | Android adaptation and compatibility work |

## Objectives

- Document the technical history of classic mobile titles.
- Organize each game in a dedicated directory with its own notes and files.
- Explore compatibility with modern Android releases.
- Preserve original gameplay characteristics where technically possible.
- Record tested builds and changes to make regressions easier to identify.

## Repository structure

```text
games/
  Diamond-Rush/
    README.md
```

## Development status

**Project under construction.** Game adaptations are ongoing and should be evaluated individually. A repository commit or CI build does not guarantee full playability on every supported Android device.
